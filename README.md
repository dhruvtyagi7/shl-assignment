# SHL Assessment Recommender

A conversational AI agent that helps hiring managers find the right SHL Individual Test Solutions through natural dialogue.

## Quick Start

### 1. Prerequisites

- Python 3.11+
- A free [Google AI Studio](https://aistudio.google.com/app/apikey) API key

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure environment

```bash
cp .env.example .env
# Edit .env and set your GEMINI_API_KEY
```

### 4. Generate the catalog (run once)

```bash
python scraper.py
```

This crawls SHL's product pages, extracts all Individual Test Solutions, and saves them to `catalog.json`. The server reads this file at startup — it never re-scrapes during live requests.

> **Note:** If the scraper returns 0 items, SHL may have changed their page structure. See the **Troubleshooting** section below.

### 5. Run the server locally

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

The server starts at `http://localhost:8000`.

### 6. Test it

```bash
# Health check
curl http://localhost:8000/health

# Start a conversation
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"messages": [{"role": "user", "content": "I am hiring a Java developer"}]}'

# Run the full test harness (server must be running)
python tests/test_conversations.py

# Run the module smoke tests (no server needed)
python test_modules.py
```

## API Reference

### `GET /health`

Returns `{"status": "ok"}` with HTTP 200. Always available.

### `POST /chat`

**Request:**
```json
{
  "messages": [
    {"role": "user", "content": "I need an assessment for a sales manager"},
    {"role": "assistant", "content": "..."},
    {"role": "user", "content": "Senior level, needs personality test"}
  ]
}
```

**Response:**
```json
{
  "reply": "Based on your requirements, here are my recommendations...",
  "recommendations": [
    {
      "name": "OPQ32",
      "url": "https://www.shl.com/products/assessments/personality-assessment/opq/",
      "test_type": "Personality & Behavior"
    }
  ],
  "end_of_conversation": true
}
```

**Key behaviours:**
- `recommendations` is `[]` while the agent is still asking clarifying questions
- `recommendations` has 1–10 items once the agent commits to a shortlist
- `end_of_conversation` is `true` only after a final shortlist is delivered
- Every URL in `recommendations` comes from the scraped catalog — never invented

## Deployment (Render.com Free Tier)

1. Push this repo to GitHub (make sure `catalog.json` is committed).
2. Go to [render.com](https://render.com) → New → Web Service → connect your repo.
3. Set:
   - **Runtime**: Docker (uses the included `Dockerfile`)
   - **Environment Variables**: Add `GEMINI_API_KEY` = your key
4. Deploy. Render provides a public HTTPS URL.

> The free tier sleeps after 15 minutes of inactivity. The `/health` endpoint will wake it up — allow up to 2 minutes on cold start.

### Alternative: Railway / Fly.io

Both support Dockerfile deploys. Set `GEMINI_API_KEY` as a secret environment variable in their dashboards.

## Architecture

```
POST /chat
    │
    ▼
[Pydantic Validation]  ← Returns 422 if request is malformed
    │
    ▼
[Guardrails] ─── injection / off-topic? ──→ Refusal response (no LLM call)
    │
    ▼
[TF-IDF Retrieval]  ← Query built from recent user messages
    │                ← Returns top-12 catalog items by cosine similarity
    ▼
[Gemini 2.5 Flash]  ← System prompt + full history + retrieved catalog items
    │                ← Low temperature (0.3) for consistent JSON output
    ▼
[Post-processing]   ← Validate all URLs against catalog (drop hallucinations)
    │                ← Enforce 1–10 item limit
    ▼
[ChatResponse]
```

**Why TF-IDF over sentence-transformers + FAISS?**

The SHL catalog has ~50–200 items. TF-IDF with bigrams:
- Loads in <100 ms — no model download on cold start
- Achieves competitive Recall@10 on the short, keyword-rich catalog descriptions
- Stays well under the 30-second response budget
- Upgrade path: swap `TfidfVectorizer` for a transformer encoder if Recall@10 drops below 70%

## Troubleshooting

### Scraper returns 0 items

SHL may have changed their page structure. Options:
1. Open DevTools on an SHL product page → inspect the product title/description elements → update the selectors in `scraper.py`.
2. Manually populate `catalog.json` with known product URLs.

### 500 errors on /chat

Check that `catalog.json` exists and `GEMINI_API_KEY` is set. Quick check:
```bash
python -c "from retrieval import CatalogRetriever; r = CatalogRetriever(); print(len(r.catalog), 'items')"
```

### Gemini rate limits

Set `GEMINI_MODEL=gemini-2.5-flash-lite` in `.env` for a faster, cheaper model, or switch to `gemini-2.0-flash` for a more affordable option.
